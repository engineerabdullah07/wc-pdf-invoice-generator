Automatically generate beautiful, print-ready PDF invoices for every WooCommerce order with custom branding and tax numbers.

== Description ==

**PDF Invoice Generator for WooCommerce** provides an effortless, automated billing solution for your online store.

Every order gets an auto-incrementing invoice number, professional layout, custom company branding, tax IDs (NTN/STRN/VAT), customer notes, and a 1-click Print/Save as PDF button.

### Key Features:
* 🧾 **Automatic Invoice Numbering**: Sequential numbering with custom prefixes (e.g., `INV-1001`).
* 🎨 **3 Elegant Template Styles**: Choose between Classic, Modern, and Minimalist invoice designs.
* 🏢 **Full Company Branding**: Upload your company logo, address, phone, email, and tax registration IDs.
* 📄 **Print-to-PDF Optimized**: Built-in CSS media queries tailored specifically for crisp A4 paper printing and PDF export.
* 📧 **Email Integration**: Adds an invoice view/download link in order confirmation emails.
* 👤 **Customer Self-Service**: Customers can view and print invoices directly from their "My Account" orders dashboard.
* 🛡️ **Admin Quick Actions**: Download and view invoices right from the WooCommerce Orders admin list and order edit pages.
* ⚡ **Super Lightweight**: No bloated PHP PDF libraries; loads in milliseconds.

== Installation ==

1. Upload the `wc-pdf-invoice-generator` folder to `/wp-content/plugins/`.
2. Activate the plugin via the 'Plugins' menu in WordPress.
3. Go to **WooCommerce > Settings > PDF Invoices** to enter your company details and logo.
4. Save settings and enjoy automated professional invoicing!

== Frequently Asked Questions ==

= Does this require heavy third-party PHP libraries? =
No! This plugin uses a clean, modern HTML + Print-to-PDF approach that keeps your site fast and works reliably across all hosting environments.

= Can customers download their past invoices? =
Yes! Logged-in customers can view and download invoices from their My Account > Orders page.
